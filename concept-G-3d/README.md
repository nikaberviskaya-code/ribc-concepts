# Российско-Индийский деловой совет — концепт G (3D и градиенты)

Статический сайт, без сборки. Структура блоков повторяет ribc.sber.bank.in:
шапка → hero → три столпа → «От диалога к результатам» → цитата → направления (8 отраслей) → мероприятия → новости → баннер про рупии → форма заявки → подвал.

```
index.html        разметка
css/style.css     токены, секции, адаптив
js/boot.js        включает режим анимаций до первого кадра
js/main.js        меню, форма, счётчики, GSAP / ScrollTrigger
js/scene3d.js     three.js: один холст поверх страницы, 3D-объекты привязаны к блокам .a3d
vendor/           gsap, ScrollTrigger, three.iife.js (локально, работает офлайн)
assets/portrait.webp
```

## Запуск
Открыть `index.html` двойным щелчком — сервер не нужен.

## Как устроены 3D-объекты
В вёрстке стоит пустой `<span class="a3d" data-3d="ring" data-g="emerald">`. `scene3d.js` рисует форму в его прямоугольнике.
Атрибуты: `data-3d` — форма (cluster, ring, orb, pill, pillow, knot, stairs, coin), `data-g` — градиент (mint, lime, saffron, emerald, ivory),
`data-tilt` — начальный поворот в градусах, `data-shadow="1"` — контактная тень, `data-par` — сила реакции на курсор.
Без WebGL вместо объектов остаются CSS-шары; при `prefers-reduced-motion` сцена статична.

## Дополнительные блоки из Figma (можно убрать)
Строка показателей «15% / $100 млрд» (`.stats`) и шесть карточек «Платежи и FX…» (`[data-extra=figma]`) — их нет на исходном сайте.

## Состояние ошибки формы
Откройте страницу с `#join-error` и отправьте корректную форму — появится экран «Что-то пошло не так».

## Шрифты
Unbounded (заголовки, цифры) и Onest (текст) — Google Fonts, нужен интернет, иначе системные.
