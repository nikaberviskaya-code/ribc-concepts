# Российско-Индийский деловой совет — концепт I (тёмная тема)

Статический сайт, без сборки. Логическая структура 1:1 с ribc.sber.bank.in:
шапка → hero → три столпа → «От стратегического диалога — к реальным результатам» (4 шага) → руководство и цитата → 8 направлений →
мероприятия (3 + счётчик «20») → новости (6) → баннер про рупии → форма заявки (успех и ошибка) → подвал.
Блоков из Figma (строка «15% / $100 млрд», карточки «Платежи и FX…») здесь нет — только то, что есть на оригинале.

## Референсы (коллекция Mobbin «RIBC — 3D references»)
- Craft — тёмно-зелёная сцена, светлая антиква на весь экран, курсивная вторая строка, шелковый градиент → hero
- Slash — чёрная сцена, курсив-акцент в заголовках, металлические карточки, пилюли-кнопки, график с золотым свечением → столпы, кнопки, баннер про рупии
- Revolut — веер монет с рифлёным ободком → баннер про рупии и третий столп
- Stripe — переливающиеся ленты → блок мероприятий

## Запуск
Открыть `index.html` двойным щелчком — сервер не нужен.

```
index.html     разметка (SVG-спрайт с иконками и градиентами в начале)
css/style.css  токены, секции, адаптив
js/boot.js     включает режим анимаций до первого кадра
js/main.js     монеты (CSS 3D), меню, форма, превью новостей, GSAP / ScrollTrigger
vendor/        gsap, ScrollTrigger (локально, работает офлайн)
assets/portrait.webp
```

## Палитра и шрифты
Фон #04100B → #0A1F16, текст #EEF1E8, акценты: изумруд #2BD67B, мята #9BF2C6, шафран #F2994A (отсылка к Индии), лаванда только в градиенте hero.
Cormorant Garamond (заголовки, цифры) + Inter (текст) — Google Fonts, нужен интернет, иначе системные.

## Состояние ошибки формы
Откройте страницу с `#join-error` и отправьте корректную форму.
